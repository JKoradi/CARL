# Getting started

The working Python source code has not yet been uploaded, so installation commands are not available.

Intended environment: Raspberry Pi 4, mjbots Pi3Hat, Moteus controllers, Python virtual environment, and optional Bluetooth Xbox controller.

Before running code, check power ratings, CAN wiring, motor IDs, directions, joint limits, communication timeouts, and emergency-stop behavior. Test individual motors with the robot safely supported before multi-joint movement.
